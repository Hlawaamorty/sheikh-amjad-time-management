# مقتطفات مرجعية من وثيقة المواصفات

هذا المجلد يحتفظ بأكواد مختارة ظهرت داخل رسالتك حتى تبقى قابلة للمقارنة دون خلطها بالنسخة المقترحة القابلة للتشغيل.

- `schema_excerpt_original.sql`: مقتطف SQL الأصلي كما ورد في الوثيقة. **لا تشغّله**؛ توجد فيه أخطاء بنيوية/أمنية.
- `font-scaling-original.css`: CSS الأصلي لتدرج أحجام الخطوط.
- `reduced-motion-original.css`: CSS الأصلي لاحترام تقليل الحركة.
- `audio-recorder-original.js`: دالة تهيئة التسجيل الصوتي الأصلية.
- `api-endpoints-reference.md`: ملخص مسارات API المذكورة في الوثيقة.

النسخة التي تُعدّ قاعدة تشغيل للمشروع موجودة في `supabase/migrations/001_schema.sql` والواجهة في `frontend/`. لم تُغيّر الملفات المرجعية بغرض إصلاحها؛ لذلك لا تستخدمها مباشرة في النشر.
