# فهرس الملفات: الاسم والوظيفة ومكان الاستخدام

| المسار | الوظيفة | أين يُستخدم؟ |
|---|---|---|
| `frontend/_headers` | رؤوس HTTP أساسية للأمان على Cloudflare Pages | جذر ملفات الواجهة المنشورة |
| `frontend/index.html` | الهيكل المرئي للصفحات | يُنشر مع الواجهة على Cloudflare Pages |
| `frontend/assets/css/design-tokens.css` | ألوان Dark/Light | ملف CSS يرتبط من index.html |
| `frontend/assets/css/typography.css` | أحجام الخط 1–6 | ملف CSS يرتبط من index.html |
| `frontend/assets/css/animations.css` | تقليل الحركة | ملف CSS يرتبط من index.html |
| `frontend/assets/css/app.css` | تخطيط الواجهة المتجاوب | ملف CSS يرتبط من index.html |
| `frontend/assets/js/config.js` | رابط Supabase والمفتاح العام | يعدّل محليًا ثم يُنشر مع الواجهة |
| `frontend/assets/js/app.js` | منطق الواجهة وطلبات Supabase | ينفذه المتصفح |
| `frontend/translations/*.json` | النصوص الأساسية لكل لغة | ملفات مرجعية لاستكمال i18n |
| `supabase/migrations/001_schema.sql` | الجداول وRLS وStorage | Supabase Dashboard → SQL Editor |
| `reference-snippets/*` | مقتطفات الأكواد الأصلية للمراجعة | مرجع فقط، لا تضعها محل الملفات العاملة |
| `ops/keep_alive.example.yml` | مثال فحص نشاط اختياري | يُنسخ فقط إلى `.github/workflows/` بعد فهم حدوده |

- `docs/اختبارات_القبول.md`: قائمة تحقق للصلاحيات والتشغيل قبل الاستخدام الحقيقي.
