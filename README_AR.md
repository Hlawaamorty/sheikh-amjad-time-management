# حزمة منظومة إدارة الوقت والمهام — نسخة البداية

ابدأ بقراءة `docs/دليل_التشغيل_والنشر.md` قبل رفع أي ملف.

## نقطة مهمة عن طلب «عدم تغيير الأكواد»

المواصفات المرسلة تحتوي مقتطفات SQL وCSS وJavaScript وبعض جداول وصفية، لكنها لا تحتوي على مستودع الموقع الكامل أو جميع الأكواد اللازمة لكل صفحة. للحفاظ على الأكواد المذكورة دون إصلاحها أو تغيير معناها، وضعت المقتطفات في `reference-snippets/`. بعضها غير قابل للتشغيل بمفرده، لذا **لا ترفع الملفات المرجعية ولا تشغّل SQL المرجعي**.

أما `frontend/` و`supabase/migrations/001_schema.sql` فهي نسخة بداية منظمة أنشئت لاستكمال ما ينقص لتجربة تشغيل فعلية. لم أسمّها نسخة مطابقة للواجهة الأصلية أو كودًا إنتاجيًا مكتملًا.

## روابط الملفات الأساسية

- دليل التشغيل بالعربية: `docs/دليل_التشغيل_والنشر.md`
- واجهة الموقع: `frontend/index.html`
- بيانات الاتصال: `frontend/assets/js/config.js`
- منطق الواجهة: `frontend/assets/js/app.js`
- المخطط المصحح وقواعد الأمان: `supabase/migrations/001_schema.sql`
- مقتطفاتك المرجعية: `reference-snippets/`

## تنبيه أمني

مفتاح `anon/publishable` فقط مسموح به في الواجهة. لا تضع مفتاح `service_role` أو كلمة مرور قاعدة البيانات في HTML/JS أو مستودع GitHub. لا تعتمد على عبارة «الملاحظة مخفية» في الواجهة وحدها؛ الأمان الفعلي يكون في سياسات قاعدة البيانات.
